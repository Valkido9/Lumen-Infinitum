# 永恒流光开屏

入口：`index.html`。动画及样式：`assets/lumen-cinema.js`、`assets/lumen-cinema.css`。

参考 [RhineLabUI](https://github.com/LBEILC/RhineLabUI) 的分阶段几何启动演出；本实现自行绘制 Canvas 图形，没有复制参考项目的品牌、模型或音乐。

## 时间轴

- 0–6 秒：定位网格、逐笔无穷符号、七层机械圆环。
- 6–10 秒：反向扫描环、金色节点、扫描平面。
- 8–13 秒：透视档案阵列形成加速隧道。
- 12–14.6 秒：机械结构收束到中心。
- 14.60 秒：在同一深色空间中，同时显现「永恒流光」与英文；随后显示「点击阅读」。

音乐使用现有 `music/开幕.mp3`。14.60 秒是对其 15 秒附近波形按 25ms 窗口分析后选取的音头。`data-reveal-time` 控制显现时间。自然有声播放时，阶段采样 `audio.currentTime`；缓冲不会使动画自行跑到前面。

## 交互与回退

开屏覆盖界面并锁定滚动，正文元素暂设 inert。动画中点击空白或按 Enter / 空格可立即跳到标题；标题出现后点击阅读关闭开屏、恢复正文交互并淡出音乐。正文自己的区域音乐在开屏关闭后接管。透视圆环、立体棱柱、斜向梁架与红铜色几何切面从头到尾持续运动，鼠标位置轻微影响空间视角。

进入页面立即播放动画并尝试自动播放音乐，不显示开始按钮。浏览器阻止有声自动播放时动画继续，首次点击跳到标题并尝试启用声音；无法绕过浏览器的自动播放权限。保留用户之前的静音偏好。音乐不可用时采用无声时间轴；减少动态效果偏好下保留时间和标题显现，取消镜头运动。

后台标签暂停音乐与绘制；返回后续播。进入正文后停止动画并暂停开屏音频。带章节锚点的直接访问跳过开屏。

## 已验证

- 实际有声自动播放、受限时无声动画自动运行及点击解锁。
- 音乐时间 14.60 秒的强音头触发标题显示。
- 开屏滚动锁定、点击退出后的正文目录恢复。
- 390px 手机画面、320px 与减少动态效果、静音偏好。
- 音乐请求失败时的无声回退、章节链接直达。
